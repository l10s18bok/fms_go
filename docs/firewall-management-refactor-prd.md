# 방화벽 관리 탭 UI 재구성 PRD

## 1. 개요

### 1.1 목적
방화벽 관리 탭의 UI를 파일 기반 관리 시스템으로 재구성합니다. 기존 `templates.json` 단일 파일 방식에서 `data` 디렉토리 내 개별 파일 방식으로 전환합니다.

### 1.2 배경
- 현재: 라디오 버튼 목록 + 텍스트 편집기/룰 빌더/NAT 빌더 서브탭
- 목표: 파일 목록 테이블 (초기화면) + 동적 편집 탭 (파일별)

### 1.3 참조
- 패키지 관리 탭 (`program_tab.go`) UI 패턴 참조
- 공통 컴포넌트 (`component/table.go`, `component/button.go`) 활용

## 2. 기능 요구사항

### 2.1 초기화면 (방화벽 관리 - 파일 목록)

#### 2.1.1 테이블 구성
| 컬럼 | 너비 | 설명 |
|------|------|------|
| 선택 | 50 | 체크박스 |
| 파일이름 | 200 | 파일명 (예: rules-v1_0_1.txt) |
| 만든 날짜 | 180 | 파일 생성 시간 |
| 수정한 날짜 | 180 | 파일 수정 시간 |
| 버전 | 100 | 파일명에서 추출한 버전 |

#### 2.1.2 버전 추출 규칙
- 파일명 형식: `{이름}-{버전}.txt`
- 예시: `rules-v1_0_1.txt` → 버전: `v1.0.1`
- `_`를 `.`로 변환
- 형식이 맞지 않으면 `-` 표시

#### 2.1.3 버튼
- **삭제**: 체크된 파일들 삭제 (확인 다이얼로그)
- **파일추가/수정**: 파일 추가/수정 다이얼로그 표시

#### 2.1.4 검색
- SearchBox 컴포넌트 사용
- 파일명, 버전으로 검색

#### 2.1.5 페이지네이션
- PagedTable 컴포넌트 사용
- `<< page 1/10 >>` 형태

#### 2.1.6 Row 더블클릭
- 해당 파일의 편집 탭을 새로 열기
- 이미 열려있으면 해당 탭으로 포커스 이동

### 2.2 파일추가/수정 다이얼로그

#### 2.2.1 UI 구성
```
┌─────────────────────────────────────────────┐
│           파일 추가/수정                     │
├─────────────────────────────────────────────┤
│  선택:     [파일생성 ▼]                      │
│            - 파일생성                        │
│            - 파일찾기                        │
│                                             │
│  파일명:   [___________________]            │
│                                             │
│            [찾아보기...]   (파일찾기 시 표시) │
│                                             │
│           [취소]      [완료]                 │
└─────────────────────────────────────────────┘
```

#### 2.2.2 동작
1. **파일생성 선택 시:**
   - 파일명 입력 활성화
   - 찾아보기 버튼 숨김
   - 완료 클릭 → 빈 파일 생성 → 편집 탭 열기

2. **파일찾기 선택 시:**
   - 파일명 입력 (읽기 전용, 자동 채워짐)
   - 찾아보기 버튼 표시
   - 찾아보기 클릭 → .txt 파일 선택
   - 완료 클릭 → 파일 복사 → 편집 탭 열기

### 2.3 편집 탭 (방화벽관리/{파일명})

#### 2.3.1 탭 이름
- 형식: `방화벽관리/{파일명}`
- 예시: `방화벽관리/rules-v1_0_1.txt`
- 25자 초과 시 `...` 처리
- 예시: `방화벽관리/very-long-name...`

#### 2.3.2 UI 구성
```
┌─────────────────────────────────────────────────────────────┐
│ [목록보기] [Firewall] [NAT]                [+ 추가] [저장]  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  (서브탭 내용 - 기존 template_tab.go 로직 재사용)           │
│                                                             │
│  - 목록보기: 텍스트 편집기 (MultiLineEntry)                 │
│  - Firewall: RuleBuilder                                    │
│  - NAT: NATBuilder                                          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

#### 2.3.3 저장 다이얼로그
```
┌─────────────────────────────────────────────┐
│           파일 저장                          │
├─────────────────────────────────────────────┤
│                                             │
│  파일명:   [ rules-v1_0_1.txt ]             │
│                                             │
│           [취소]      [저장]                 │
└─────────────────────────────────────────────┘
```

### 2.4 데이터 저장

#### 2.4.1 저장 위치
- 경로: `{실행파일경로}/data/`
- config 디렉토리와 동일 레벨

#### 2.4.2 파일 형식
- 확장자: `.txt`
- 내용: 방화벽 규칙 텍스트 (기존 Contents 필드 내용)

#### 2.4.3 메타데이터
- 만든 날짜: 파일 시스템의 생성 시간
- 수정한 날짜: 파일 시스템의 수정 시간
- 버전: 파일명에서 추출

### 3.1 하위 호환성

- `component.SearchBox`: 검색 기능

## 5. 기술 사양

### 5.1 새로 생성할 파일

| 파일 | 설명 |
|------|------|
| `model/firewall_file.go` | FirewallFile 데이터 모델 |

| `ui/firewall_tab.go` | 초기화면 (파일 목록) |

### 5.2 수정할 파일

| 파일 | 변경 내용 |
|------|-----------|
| `main.go` | data 디렉토리 초기화, FileStore 생성 |
| `ui/app.go` | FirewallTab 통합, 동적 탭 관리, Import/Export 수정 |

## 6. 데이터 모델

### 6.1 FirewallFile
```go
type FirewallFile struct {
    FileName    string    // 파일명 (예: rules-v1_0_1.txt)
    FilePath    string    // 전체 파일 경로
    CreatedAt   time.Time // 만든 날짜
    ModifiedAt  time.Time // 수정한 날짜
    Version     string    // 버전 (파일명에서 추출)
    Contents    string    // 파일 내용
}
```

### 6.2 버전 추출 함수

```go
// extractVersion 파일명에서 버전 추출

func extractVersion(fileName string) string
```
